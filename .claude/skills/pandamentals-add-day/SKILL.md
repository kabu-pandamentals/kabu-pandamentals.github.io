# PANDAMENTALSに新しい日付データを追加する

`index.html` はビルド不要の単一静的ページ。日次データはすべて `<script>` 内の `DATA` オブジェクトに `"YYYY-MM-DD"` キーで1エントリずつ持たせている。新しい日を追加するには、HTML側のセレクター1箇所と、DATA内のエントリ1つを追加するだけでよい。他のロジック（レンダリング関数・日付切り替えハンドラ）は一切変更しない。

## 手順

### 1. 対象日を確認する
ユーザーから日付が明示されていなければ確認する。年・月をまたぐ場合は `yearSelect` / `monthSelect` の `<option>` も追加が必要になる（通常は月内の日付追加が多いので `daySelect` だけで済むことが多い）。

### 2. 日付セレクターに `<option>` を追加
`<select id="daySelect">` 内、既存の `<option>` の後ろに追加する。曜日を計算して明記すること（例: `<option value="28">28日（火）</option>`）。既存の `selected` 属性は動かさなくてよい — 新しいオプションを増やすだけで、ユーザーがそれを選択すれば表示が切り替わる。

### 3. `DATA` オブジェクトに新しいエントリを追加
最後の既存エントリの直後（`};` の直前）に、カンマ区切りで `"YYYY-MM-DD": { ... }` を追加する。スキーマは以下の通り、既存エントリと完全に揃えること（キー名・ネスト構造を変えない）。

```js
"YYYY-MM-DD": {
  nikkei: { value:"...", delta:"...", note:"..." },
  upStocks: [ /* StockCard */ ],
  downStocks: [ /* StockCard */ ],
  featuredStocks: [ /* StockCard */ ],
  ipoStocks: [ /* IpoStockCard */ ]
}
```

**StockCard**（upStocks / downStocks / featuredStocks 共通）:
```js
{
  code:"銘柄コード", name:"銘柄名", market:"市場（例: 東証プライム）",
  site:"公式サイトURL", tv:"TradingViewシンボル（例: TSE-1234）",
  price:"現在値（カンマ区切り文字列）", chg:"騰落率（例: +18.92%）",
  marketCap:"時価総額",
  biz:"事業内容の説明",
  chart:[0, ..., 最終値],   // 前日終値=0起点の数値配列。sparklineに使われる
  detail:"値動きの背景（材料・経緯）",
  outlook:"翌営業日の視点"
}
```
`featuredStocks` は `upStocks` と同一スキーマでよい（描画時に色は常に「up」扱いになる仕様なので、値上がり値下がりどちらの銘柄を入れても構わない）。

**IpoStockCard**（ipoStocks用。StockCardと似ているが`chart`ではなく`charts`と`dir`を持つ）:
```js
{
  code:"...", name:"...", market:"...", dir:"up または down",
  site:"...", tv:"...",
  price:"...", chg:"...", marketCap:"...",
  biz:"...",
  charts:{ "1日":[...], "5日":[...], "1カ月":[...] },
  detail:"...", outlook:"..."
}
```

### 4. データの中身を用意する
- **実データがある場合**: ユーザーから受け取った数値・銘柄情報をそのまま使う。
- **実データがまだない場合（動作確認目的）**: 架空のサンプルデータを作る。実在の企業と誤認されないよう、銘柄名は「サンプル◯◯」「テスト◯◯」のような明らかに架空とわかる名前にし、`biz` / `detail` / `outlook` の文中にも「（サンプル）」と明記する。銘柄コードも実在しなさそうな番号（例: 9999, 8888など）を使う。件数は上げ2件・下げ2件・注目1〜2件・IPO1件程度で十分。

### 5. ブラウザで動作確認する
`mcp__Claude_Browser__navigate` で `index.html` を開き（または既に開いていれば再読み込み）、`read_page` で日付セレクター（`daySelect`）の要素を取得し、`form_input` で追加した日付を選択する。その後 `get_page_text` でページ内容を取得し、以下を確認する:
- 日経平均の値・前日比・コメントが新しいエントリの内容に切り替わっている
- ストップ高/ストップ安/注目/IPOの件数バッジが、追加した配列の件数と一致している
- 各銘柄カードの銘柄名・価格・騰落率が正しく表示されている

数値が反映されていなければ、DATA内のキー名のタイプミス（`"YYYY-MM-DD"` の形式ズレなど）や、直前エントリとの間のカンマ抜けを疑う。

## 注意点
- レンダリング関数（`renderStocks` / `renderIPOStocks` / `sparkline` / `renderDate` など）やCSSは変更しない。データを追加するだけで表示は自動的に対応する。
- `chart` / `charts` の数値配列は「前日終値からの変化率(%)」を時系列で並べたもの。最初の要素は必ず `0`。
- 既存の日付エントリ（例: `2026-07-24`）を書き換えず、新しいエントリを追記する形にする。
